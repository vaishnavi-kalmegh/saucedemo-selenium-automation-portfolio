# Screenshots

Real evidence screenshots live in `docs/images/` and are regenerated by the CI workflow after every successful run on `main` (see `scripts/capture_portfolio_screenshots.py`).

This folder is only for extra, manually captured screenshots. Do not add mockups; use real images from a local or CI run.

On a test failure the framework saves a screenshot under `reports/screenshots/` (git-ignored) and attaches it to `reports/report.html`.
